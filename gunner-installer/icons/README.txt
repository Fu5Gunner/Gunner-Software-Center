Put program icons here, named <id>.png (or .svg/.webp/.jpg), e.g. curseforge.png.
Alternatively set "icon" in programs.json to a local path (relative to the app folder)
or an https:// URL (downloaded once and cached in ~/.cache/cachyos-installer/icons).
If no icon is found, the app tries your system icon theme, then a coloured letter tile.
